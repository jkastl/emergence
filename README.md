# A Field Guide to Emergence

Seven interactive simulations of complexity arising from simple rules: an
elementary cellular automaton, a boids flock, Gray-Scott reaction-diffusion,
phyllotaxis, a chaotic double pendulum, an Abelian sandpile, and L-system
plants.

The entire site is a single dependency-free `index.html`, served with GitHub
Pages from the `main` branch (Settings, Pages, Deploy from branch, `main`,
root folder).
